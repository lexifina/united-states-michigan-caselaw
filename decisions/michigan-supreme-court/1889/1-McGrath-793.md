# Peckham v. Circuit Judge

## Majority

To compel respondent to vacate an order setting aside an execution levy upon a judgment against an. estate, where the writ was levied on lands which had belonged to the decedent, and upon application of the administrator the levy was set aside and the execution recalled.
Denied February 20, 1889.
