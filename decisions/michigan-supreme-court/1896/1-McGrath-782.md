# William Wright Co. v. Circuit Judge

## Majority

To set aside an order vacating a nulla bona return to an execution, upon which a creditor’s bill has been since filed.
Denied April 21, 1896, with'costs, on the ground that the showing that relators were entitled to have the return sustained, was not so clear as to justify interference by this court by mandamus.
