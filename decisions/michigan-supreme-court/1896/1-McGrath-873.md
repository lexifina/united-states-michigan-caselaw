# Potvin v. Circuit Judge

## Majority

To compel respondent to set aside a verdict, grant a new trial and receive testimony offered under defendant’s notice, the court having ruled that the matters set up in the notice, if shown, did not constitute a valid defense to the note sued upon.
Order to show cause denied July 1, 1896.
