# Celina Mutual Insurance v. Preferred Risk Mutual Insurance

## Majority

The motion by plaintiff and appellant for leave to file delayed application for rehearing is treated as a motion for reconsideration of this Court’s order dated January 9, 1976 (395 Mich 825), and so considered, the same is hereby denied, because it does not appear that said order was entered erroneously.
