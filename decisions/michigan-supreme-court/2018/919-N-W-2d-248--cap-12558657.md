# Woodley v. Ionia Corr. Facility Warden

## Majority

On order of the Court, the application for leave to appeal the September 18, 2017 order of the Court of Appeals is considered, and it is DENIED, because we are not persuaded that the question presented should be reviewed by this Court. The motion to file an original action is DENIED.
